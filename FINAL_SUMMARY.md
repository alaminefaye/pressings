## 🚀 COMMENT UTILISER LE DASHBOARD ADMIN

### 1. Se connecter
```
URL: http://localhost:8000/login
Email: admin@pressing.com
Password: password
```

### 2. Naviguer dans l'interface
- **Dashboard** - Vue d'ensemble et statistiques
- **Commandes** - Gérer toutes les commandes
- **Clients** - Base de données clients
- **Services** - Configurer les services
- **Tarifs** - Modifier la grille tarifaire

### 3. Gestion d'une commande
1. Cliquer sur "Commandes" dans le menu
2. Filtrer ou rechercher une commande
3. Cliquer sur "Détails"
4. Changer le statut avec le formulaire latéral
5. Assigner un employé si nécessaire

### 4. Modifier les tarifs
1. Aller dans "Tarifs"
2. Modifier les prix directement dans le tableau
3. Cliquer sur "Enregistrer les modifications"
